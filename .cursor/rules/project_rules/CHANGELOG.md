## 🚀 Как использовать новые правила

### Для новых разработчиков
1. Начните с [QUICKSTART.md](./QUICKSTART.md)
2. Создайте первый виджет по инструкции
3. Изучите [README.md](./README.md) для навигации
4. Читайте специализированные файлы по мере необходимости

### Для опытных разработчиков
1. Используйте [README.md](./README.md) → "Быстрая навигация по задачам"
2. Обращайтесь к специализированным файлам как к справочнику
3. Используйте "Индекс ключевых тем" для быстрого поиска

### Для создания нового лендинга
1. [main.mdc](./main.mdc) → "Создание нового лендинга"
2. [QUICKSTART.md](./QUICKSTART.md) → создание секций
3. [styling.mdc](./styling.mdc) → дизайн-система
4. [performance.mdc](./performance.mdc) → чек-лист перед запуском
